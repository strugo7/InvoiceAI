מדריך חיבור Gmail ו-Google Sheets

כיצד לעבור ממצב סימולציה למצב אמת

  1. הגדרת פרויקט Google Cloud:

    כנס ל-Google Cloud Console, צור פרויקט חדש והפעל את ה-Gmail API וה-Google Sheets API.

  2. יצירת אישורי גישה (OAuth Client):

    הגדר מסך הסכמה (Consent Screen), צור מפתח מסוג Desktop App והורד אותו בשם credentials.json.

  3. מיקום הקובץ:

    העבר את קובץ ה-credentials.json לתיקיית ה-backend של הפרויקט.

  4. יצירת גיליון Google Sheets:

    צור גיליון חדש ב-Google Sheets והעתק את המזהה שלו מה-URL (התווים בין /d/ ל-/edit) לשדה ההגדרות משמאל.

  5. סנכרון ראשון:

    כבה את מצב הסימולציה, לחץ על "שמור הגדרות", ואז לחץ על "סנכרן כעת". ייפתח חלון דפדפן לאישור הגישה לחשבונך באופן מאובטח!
